# Tipping Point Analysis for Survival Endpoints

The R package **tipse** implements tipping point sensitivity analysis for time-to-event endpoints under different missing data scenarios, as described in Oodally et al. (2025) https://arxiv.org/abs/2506.19988. Supports both model-based and model-free imputation, multiple imputation workflows, plausibility assessment and visualizations. Enables robust assessment for regulatory and exploratory analyses.

## References
